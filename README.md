# 🐍 CYBER SNAKE // Neon Arcade

A modern retro arcade Snake game built with HTML5 Canvas, Web Audio API synth sounds, responsive touch & keyboard controls, and pure CSS neon aesthetics.

![Cyber Snake Preview](preview.png)

## 🎮 Features
- **Visuals**: Neon glowing aesthetic, dynamic canvas particle burst effects, animated grid floor, CRT scanline overlay.
- **Audio**: Custom built-in Web Audio API synthesizers for 8-bit sound effects (eat, bonus chime, crash explosion, retro synth bassline music) without relying on any external audio files.
- **Gameplay**:
  - Classic Snake mechanics with wall collisions and self-intersections.
  - Timed Special Energy Orbs (Bonus multipliers).
  - Progressive difficulty scaling and speed multiplier.
  - 4 Selectable Difficulty Levels (Easy, Medium, Hard, Insane).
- **Controls**:
  - ⌨ Keyboard: WASD / Arrow Keys, Spacebar for Pause/Resume.
  - 📱 Touch: Gesture swipes + On-screen Neon Virtual D-Pad.
- **Persistence**: High score saved locally via `localStorage`.

## 🚀 Deployment
Deployable anywhere in 1-click via Vercel or GitHub Pages.
